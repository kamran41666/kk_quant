## 使用规则（所有 Session 必须遵守）

### 评级体系

| 评级 | 含义 | 落地时间 |
|------|------|---------|
| **A** | 高优先级，可直接转化为代码，项目已具备基础设施 | 当前或下一个 sprint |
| **B** | 中优先级，方向明确但需要先补齐前置模块 | 阶段二或阶段三 |
| **C** | 低优先级，有价值的参考但落地路径较长 | 长期保留 |
| **D** | 启发类知识，暂不可操作但值得了解 | 不定 |

### 状态标记

每一条知识都有状态标记：
- **待采用** — 尚未被任何 session 采用
- **已采用 → [commit/PR/SHA]** — 已被实现，标注对应的 commit 或 PR 链接

> ⚠️ **强制规则：** 任何 session 在采用某条知识后，必须将状态从"待采用"改为"已采用"，并标注 commit SHA 或 PR 链接。**禁止采用后不更新状态。**

### 真实性标准

- **来源可信度**: 标注了来源类型（学术论文 / 券商研报 / 开源项目 / 个人博客 / 论坛讨论）
- 单个来源的信息标注"单源"，多个独立来源验证的标注"多源验证"
- 论坛/个人博客的信息仅作参考，标注"待验证"

### 去重机制

- 新知识入库前检查来源 URL 是否已存在
- 同主题但来源不同的知识，合并而非重复

## 1. 交易策略

### 1.1 小盘价值增强策略（四象限框架）

- **来源**: 国海证券研报（单源，券商研报）
- **评级**: **A**
- **内容**:
  - A 股四大风格象限中，**小盘价值**表现最优：年化 23.93%，夏普 1.00，超额 +13.66%
  - 策略构建流程：剔除低盈利及预期增速差的个股 → 用**低波动、反转、小市值**三个因子优选剩余个股
  - 小盘成长（年化 17.18%）、大盘成长（15.60%）、大盘价值（15.35%）均不如小盘价值
- **落地指向**: 在 `factor/builtin/` 下确保已有低波动率（`volatility_1m`）、反转（`momentum_1m` 取负）、小市值（`log_market_cap`）三个因子，然后在 `examples/` 编写 `small_cap_value_strategy.py` 组合这三个因子做截面打分
- **与现有项目的关系**: 帖主 PowerEason 正是小市值策略 + 这些因子，是一个有实盘验证的方向
- **状态**: 待采用

### 1.2 风格轮动信号：动量周期因股票池而异

- **落地指向**: 当前 `momentum.py` 中只有 `momentum_1m/3m/12m_1m`，建议根据股票池自动选择动量窗口：大盘股用较短窗口（1M-6M），小盘股用较长窗口（12M-24M）。可以在策略的 `initialize()` 中根据 `stock_list` 的市值分布动态设置

## 2. 因子研究

### 2.1 三目标 NSGA-II 遗传算法因子挖掘

- **来源**: 华泰证券研报"以空间换时间——多目标基本面选股因子挖掘框架"（单源，券商研报）
- **评级**: **B**
- **内容**:
  - 将基本面因子表达式参数化，使用三目标 NSGA-II 遗传算法挖掘
  - 优化目标：|IC|、|IC|胜率、NDCG@k 三个目标同时优化
  - 输入 71 个指标（市场表现、分析师一致预期、三大财务报表 TTM/MRQ）
  - 中证 1000 指增扣费后年化超额 32.5%，沪深 300 超额 10.1%，中证 500 超额 13.6%
  - 基本面合成因子与量价因子的长期相关性仅 0.07，具备进一步合成潜力
- **落地指向**: 如果阶段二引入遗传算法优化，核心不是找新因子，而是把现有因子做非线性组合。当前 `factor/synthesis.py` 只支持等权和 ICIR 加权，可以加 `method='genetic'`
- **状态**: 待采用

### 2.2 AlphaAgent：LLM 驱动的抗衰减因子挖掘

- **来源**: Tang, Chen, Yang et al., KDD '25（学术顶会论文，单源）
- **评级**: **B**
- **内容**:
  - 多智能体框架，三个正则化环节：原创性强制（AST 相似度 vs Alpha101）、假设-因子对齐（LLM 语义评估）、复杂度控制（AST 结构约束）
  - CSI 500 年化超额 11.0%，IR 1.5，最大回撤 < 10%
  - 有效因子命中率提升 81%，因子 IC 在四年测试期保持 0.02 以上（传统方法衰减至接近零）
  - S&P 500 年化超额 8.74%，IR 1.05
- **落地指向**: 这是前沿方向，等阶段二的 LLM 基础设施建立后再考虑。短期可参考其"复杂度控制"理念，在写新因子时用更简洁的表达式
- **状态**: 待采用

### 2.3 因子舒适区探寻

- **来源**: 华安证券研报"因材施'策'"（单源，券商研报）
- **评级**: **B**
- **内容**:
  - 从"为域选因子"向"为因子找域"转变
  - 三种偏差度量方法：OLS 残差分析法、分位数差值法、概率分布散度法
  - 分位数差值法综合最优
  - 中证 1000 增强年化超额 12.8%，信息比 2.40，2020-2024 连续五年正超额
- **落地指向**: 与 1.6 动态情景模型互补。在因子评估中加入"该因子在哪个股票池/市场状态下有效"的分析维度
- **状态**: 待采用

### 2.4 因子维度偏差-方差权衡

- **来源**: Penn 研究团队 (2025)，DiT 扩散 Transformer 研究（学术论文，单源）
- **评级**: **C**
- **内容**:
  - 因子维度存在明显的偏差-方差权衡
  - 因子太少 → 欠拟合（组合分散），因子太多 → 过拟合（组合集中，样本外表现差）
  - 存在最优中间维度（实验中最优 k=170）
  - 但 170 维度对个人投资者不现实
- **落地指向**: 对当前项目的启发：不要无限扩展因子数量，12-30 个优质因子可能比 100+ 噪声因子更好。可以作为因子数量选择的理论依据
- **状态**: 待采用

### 2.5 因子相关性管理：量价 vs 基本面

- **来源**: 华泰证券研报 + 中邮证券因子周报（多源验证，券商研报）
- **评级**: **A**
- **内容**:
  - 基本面合成因子与量价因子的长期相关性仅 **0.07**，意味着两者结合可以显著分散风险
  - 量价因子在 A 股 Alpha 属性更强但同质化严重

- **状态**: 待采用

### 2.6 随机森林非线性多因子建模

## 3. 过拟合防御

### 3.1 过拟合的金融时间序列特殊性

- **来源**: 知乎"做策略回测时如何把握有效信号与过拟合的边界"+ 叩富网（多源，行业博客）
- **评级**: **A**
- **内容**:
  - 金融时间序列非独立同分布（自相关、条件异方差、长记忆）
  - 信噪比极低（可解释结构的方差远小于扰动项）
  - 数据结构时变（regime-dependent）
  - 典型表现：参数在小邻域内微调即导致绩效剧烈波动、样本内外显著差异、换资产换频率即失效
- **落地指向**: 这些表现可以直接编码为检测指标。在评估因子/策略时，如果检测到参数微调 ±10% 导致夏普变化 > 50%，则标记为"疑似过拟合"
- **状态**: 待采用

### 3.2 参数稳健性区间

- **来源**: 微信公众号"如何在策略回测中避免过度拟合"（行业博客，单源）
- **评级**: **A**
- **内容**:
  - 稳健区间定义：`{θ | Sharpe(θ) > 0.8 × Sharpe(θ*)}`，其中 θ* 为最优参数
  - 稳健区间越大，策略越可靠
  - 参数平滑技术：`θ_smooth(t) = α·θ_optimal(t) + (1-α)·θ_smooth(t-1)`，α∈[0.1, 0.3]
  - 参数锚定：目标函数 = 原始收益 - λ·‖θ-θ_prior‖²
  - 集成参数：选择夏普前 k 组参数加权，`w_i ∝ exp(SR_i/τ)`
- **落地指向**: 在 `factor/evaluation.py` 或新建 `quant_engine/backtest/robustness.py` 中实现参数敏感性分析。输入参数网格 ±10%/±20%/±50%，输出稳健区间宽度。这是帖主 PowerEason 在帖子 #41 中强调的核心能力
- **状态**: 待采用

### 3.3 前向分析 (Walk-Forward Analysis)

- **来源**: 多源验证（quant_at_home2、行业博客、学术文献）
- **评级**: **A**
- **内容**:
  - 滚动窗口：`N = ⌊(T - W_train) / W_test⌋`
  - 训练窗口至少包含一个完整牛熊周期（A 股约 3-5 年）
  - 与普通交叉验证的关键区别：严格保持时间顺序，训练集永远在测试集之前
  - 能杀死 60-70% 的样本内拟合策略
- **落地指向**: 在 `factor/evaluation.py` 中新增 `walk_forward_analysis()` 方法。这是过拟合防御的**第一道防线**，优先级最高
- **状态**: 待采用

### 3.4 组合净化交叉验证 (Purged CV)

- **来源**: 多源验证（学术文献、行业博客）
- **评级**: **B**
- **内容**:
  - 传统 K-Fold CV 在时间序列上无效（信息泄露）
  - 净化 CV：训练/测试集之间设 h 天缓冲区（剔除与测试样本重叠的训练样本）
  - 区块时序 CV (Blocked TS CV)：按时间块而非单个观测做划分
- **落地指向**: 在 `factor/evaluation.py` 中（或独立模块）实现 `purged_cv()`，作为 WFA 的补充。阶段二引入 ML 模型时必须使用
- **状态**: 待采用

### 3.5 Deflated Sharpe Ratio (DSR)

- **来源**: 多源验证（学术文献，业界标准）
- **评级**: **B**
- **内容**:
  - 传统 Sharpe 的 p 值在多策略/多参数测试中严重失真
  - DSR 考虑"从 N 个随机策略中选出最佳"的背景
  - DSR = Prob(Sharpe > observed | N trials were conducted)
  - 公式：`DSR = P[max(SR_1..SR_N) > SR_observed]`
- **落地指向**: 当前 `analytics/metrics.py` 计算的是传统 Sharpe。建议新增 `deflated_sharpe()` 方法，输入策略夏普 + 尝试过的参数组合数，输出 DSR。用于阶段二的策略评估
- **状态**: 待采用

### 3.6 组合净化 CPCV

- **来源**: 学术文献（多源验证）
- **评级**: **B**
- **内容**:
  - 生成夏普比率分布而非点估计
  - 策略在跨 CPCV 路径上夏普方差 > 40% → 大概率过拟合
  - 比单一夏普值能更真实反映策略稳健性
- **落地指向**: 阶段二引入，用于策略最终评估
- **状态**: 待采用

### 3.7 过拟合的深层认知（OOD 分布外推 & 反身性）

- **来源**: 综合学术文献（多源验证）
- **评级**: **C**
- **内容**:
  - **分布外推 (OOD)**：市场非平稳性导致历史分布与未来分布不一致。模型失效不是因为拟合了噪音，而是过度依赖历史分布本身
  - **时间尺度错配**：微秒噪音、日频情绪、月频动量、年频宏观、十年制度变革——模型拟合了特定时间尺度的规律，换尺度即失效
  - **反身性**：集体认知趋同 → 因子拥挤 → 信号自我毁灭。2024 年 A 股大小盘因子的集体失效为典型案例
- **落地指向**: 这三个概念是更高层次的认知框架，暂不直接编码。但应作为设计新策略时的"自检清单"
- **状态**: 待采用

### 3.8 数据扰动测试

- **来源**: 行业博客 + 学术文献（多源验证）
- **评级**: **A**
- **内容**:
  - 价格噪声测试：`P'_t = P_t × (1+ε), ε~N(0,0.001)`
  - 随机删除 5% 数据点
  - 性能下降不应超过 20%
  - Block bootstrap：对日收益率做 1000 次 block bootstrap（块长=22天），构建 95% CI
  - 原始结果落在置信区间外 → 过拟合
- **落地指向**: 在 `factor/evaluation.py` 中新增 `perturbation_test()` 和 `bootstrap_confidence_interval()` 方法。这两种测试计算成本低、实现简单、诊断能力强
- **状态**: 待采用

### 3.9 蒙特卡洛模拟验证

- **来源**: 行业博客（单源，但方法成熟）
- **评级**: **B**
- **内容**:
  - 对日收益率做 block bootstrap（块长 = 22 个交易日）
  - 1000 次模拟 → 构建年化收益和最大回撤的 95% 置信区间
  - 原始回测结果与模拟分布进行比较
- **落地指向**: 可以和 3.8 合并实现，共享 bootstrap 基础设施
- **状态**: 待采用

## 4. 风控与仓位管理

### 4.1 Risk-Constrained Kelly Criterion

- **来源**: José Carlos Gonzáles Tanaka, Interactive Brokers / QuantInsti 2024（行业博客，单源）
- **评级**: **B**
- **内容**:
  - 经典 Kelly：`K% = W - (1-W)/R`（W=胜率，R=盈亏比）
  - 风险约束 Kelly（Busseti et al., 2016）：加回撤约束 `Prob(Min Wealth < α) < β`
  - 风险约束 Kelly 产生更平滑的权益曲线、更小的回撤，但累计收益较低
  - 实践建议：用**半 Kelly（f*/2）或四分之一 Kelly（f*/4）**以降低估计误差导致的波动
- **落地指向**: 在 `quant_engine/backtest/` 下新增 `position_sizing.py` 模块，实现 Kelly/半Kelly/风险约束Kelly 三种仓位管理方法。当前项目没有仓位管理模块，信号直接映射到等权持仓
- **状态**: 待采用

### 4.2 广义 Kelly Criterion 集中投资模型

- **来源**: Vukčević & Keser, arXiv 2402.15588 (2024)（学术论文，单源）
- **评级**: **C**
- **内容**:
  - 面向集中投资风格（Buffett/Munger 式），含约束：禁止做空、杠杆上限、永久性资本损失限制、最大单票上限
  - 软件已公开发布
- **落地指向**: 如果策略是帖主 PowerEason 式的"策略单吊个股，资产分散策略"风格，这个模型适用。阶段二考虑集成
- **状态**: 待采用

### 4.3 ATR 动态止损

- **来源**: GitHub 开源项目 single-stock-autotrading-china（开源项目，单源）
- **评级**: **A**
- **内容**:
  - 基于 ATR（Average True Range）的动态止损：止损价位 = 入场价 ± N × ATR

## 7. 因子衰减与拥挤

### 7.1 因子衰减的双曲线模型

- **来源**: Chorok Lee, arXiv 2512.11913 (2025)（学术论文，单源）
- **评级**: **B**
- **内容**:
  - 因子衰减遵循双曲线形式：`α(t) = K/(1+λt)`，优于线性或指数模型
  - 测试了 8 个 Fama-French 因子（1963-2024）
  - **机械因子**（动量、反转）→ 清晰的双曲线衰减（动量 R²=0.65）
  - **判断型因子**（价值、质量）→ 不拟合该模型（更持久）
  - 拥挤加速于 2015 年后，与因子 ETF AUM 增长相关（ρ=-0.63）
- **落地指向**: 对你的因子体系的影响：①技术/量价因子（机械因子）衰减更快，需要更频繁更新；②基本面因子更耐久，值得前期投入。③反映了你的 CLAUDE.md 中帖主的直觉——"不能依赖某一个因子走完全程"
- **状态**: 待采用

### 7.2 拥挤预测尾部风险而非平均收益

- **来源**: Lee (2025) + Resonanz Capital (2025)（学术论文 + 行业报告，多源验证）
- **评级**: **B**
- **内容**:
  - 拥挤主要体现为**尾部风险（崩盘概率）的增加**，而非平均收益的下降
  - 样本外（2001-2024）：拥挤的反转因子崩盘概率高 1.7-1.8 倍
  - 拥挤对风险管理有价值，但对 Alpha 预测无直接帮助
- **落地指向**: 对于风控的影响——因子拥挤度应该触发的是仓位限制（降杠杆）而非因子剔除。你可以在 `factor/evaluation.py` 中加入滚动 IC 跟踪（类似 §7.3）来监测拥挤信号
- **状态**: 待采用

### 7.3 因子衰减监测指标体系

- **来源**: 行业博客 + 学术文献（多源验证）
- **评级**: **A**
- **内容**:
  - 滚动夏普比率：SR_21, SR_63, SR_126, SR_252
    - SR_63 < 历史均值的 50% → 黄色预警
    - SR_21 < 0 → 红色预警
  - 衰减速度：`-log(R_t/R_peak) / (t-t_peak)`，> 0.01/天 → 预警
  - IC 跟踪：滚动 IC + CUSUM 突变检测，连续 3 月 IC 低于历史均值-1σ → 预警
  - 拥挤度：`max(0, ρ_t - ρ_历史75分位)`，相关性突然上升 → 预警
- **落地指向**: 这些指标可以直接编码。在 `factor/evaluation.py` 中新增 `factor_health_monitor()` 方法，对每个因子定期计算以上四个指标并输出预警
- **状态**: 待采用

### 7.4 因子衰减三种模式

- **来源**: 行业经验总结（多源验证）
- **评级**: **B**
- **内容**:
  | 衰减模式 | 特征 | 应对 |
  |---------|------|------|
  | 单调衰减 | 持续性性能下降 | 降低复杂度/加正则化/考虑退役 |
  | 周期性衰减 | 收益呈周期波动 | 识别周期模式/动态调整权重 |
  | 突变衰减 | 断崖式下跌 | Regime detection 系统/应急预案 |
- **落地指向**: 在 7.3 的监测指标基础上，加衰减模式分类器。对每种模式预定义应对策略
- **状态**: 待采用
