# Phase 4C：跨市场纸面组合与策略观察计划

> 文档状态：Phase 4C 阶段计划与当时验收范围。blocked 计划 retry 后续已实现；剩余的计划明细、审批 UI 和真实成交回填以 [`project-state-audit-2026-09-09.md`](project-state-audit-2026-09-09.md) 为准。

## 目标

在不接入真实账户、不发送真实订单的前提下，把 A 股、国内基金和美股纳入同一个可审计的纸面组合工作台。用户可以选择市场、查看可用资金和持仓、提交模拟订单，并在有完成回测证据的前提下运行有限期策略观察。

所有执行结果必须继续标记 `execution_mode=paper_only`、`live_execution=false`。公开行情只用于研究或模拟，不得被描述为交易所级实时数据。

## 统一但显式的市场规则

| 市场 | 代码示例 | 纸面数量规则 | 结算/估值规则 | 当前数据边界 |
| --- | --- | --- | --- | --- |
| A 股 | `000001.SZ` | 100 股整手 | 买入 T+1 可卖；按有效报价估值 | Tencent/AKShare 低频公开行情 |
| 国内基金 | `110022` | 按份额，可支持小数精度由基金规则配置 | 以基金净值日终估值；不得伪造盘中成交 | Eastmoney NAV，可能延迟 |
| 美股 | `AAPL` | 默认整股 | 按 USD 报价估值；交易时段由市场日历判断 | Yahoo Chart，公开源、可能延迟 |

规则必须由服务端 `MarketSpec` 校验，前端只负责展示和友好提示，不能通过修改请求绕过限制。

## 交付项

1. 纸面账户支持市场/币种维度的现金、持仓、订单、成交、估值和账本记录；历史 A 股数据迁移为 `CNY`/A 股，不改变既有结果。
2. 订单请求带 `market`，根据市场校验代码、数量精度、价格来源、报价时效、交易日和现金；未知或过期报价 fail-closed。
3. 跨市场行情详情页可以直接创建对应市场证券的纸面订单；指数详情页仅供观察，不提供交易入口；订单确认页明确“模拟成交，不连接券商”。
4. 策略观察支持选择市场适用的策略；每个自动订单记录 `observation_id`/`strategy_id`，同一账户的不同观察任务不能互相消费策略批次。
5. 调度器按市场日历触发观察和估值；基金没有盘中行情时不生成虚假的实时成交，只在有效 NAV 观察点处理。
6. `/paper` 提供市场切换、规则说明、持仓/订单/事件过滤和跨币种摘要；手动仓位与策略仓位边界可解释。
7. 增加服务层、HTTP 层、迁移、并发、断源、幂等和浏览器链路测试，并由未参与实现的 agent 独立复核。

## 明确不包含

- 真实券商登录、真实账户余额读取、真实下单/撤单、真实成交回报或资金转移。
- 把 Yahoo/Eastmoney/Tencent/AKShare 公开接口当作有 SLA 的实时交易源。
- 未有历史数据和回测证据时自动推荐或自动交易。

## 阶段门禁

- C1：服务端市场规则和纸面订单闭环，后端全量回归通过。基金订单/估值必须复用市场接口登记并持久化的 Eastmoney NAV 证据（代码、价格、源时间、freshness 完全匹配），不能仅靠请求字段自称官方数据；历史请求不得使用晚于 `trade_date`/`valuation_date` 的 NAV；主要指数代码在服务端拒绝交易。
- C2：跨市场策略观察、批次隔离和调度器，独立 agent 无 P0/P1。基金策略信号已按独立证据切片开放：必须绑定 `cn-fund` 回测、不可变 NAV 数据集和 `next_valid_nav-v1`；美股观察继续明确返回 `strategy_observation_requires_a_share_account`。多观察任务通过 `PaperLot.owner_id` 隔离；调度器按市场独立校验来源、源时间、freshness、交易日并估值，适配器缺失或断源时只延后对应市场，历史日期需 provider 明确声明 replay 能力。基金与 A 股实时观察均采用持久化再平衡计划、全量现金/仓位预检、卖出优先、逐项幂等恢复和 60 秒可过期租约/心跳；blocked 计划已有 retry API，计划明细/审批界面、人工成交回填和美股策略信号仍未完成，不能据此宣称整个 Phase 4C 完成。
- C2：估值接口与记录同时保存聚合字段和逐持仓报价证据（价格、来源、源时间、freshness），调度器通过 WebSocket/页面轮询刷新已提交的 paper-only checkpoint；无穷大、无效或未来时间戳报价会在市场边界被拒绝。
- 证据绑定基础层：回测 Run 记录市场、策略指纹、数据 manifest、数据截止日、日历版本和执行模型；策略观察关联具体 `backtest_run_id`，创建/启动时重新校验指纹与证据状态。旧版无证据 A 股记录仅保留兼容读取，不得作为跨市场授权依据。
- C3：前端市场切换、下单确认、持仓/账本可解释，Playwright 通过桌面和窄屏链路。
- C4：文档、迁移、故障降级和 `paper_only` 反向测试通过后，才可标记 Phase 4C 完成。
