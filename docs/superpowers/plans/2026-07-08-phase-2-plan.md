## 概述

在阶段一（研究平台）的基础上，构建面向个人使用的 Web 交易平台 + 模拟账户系统。

**核心目标**: 策略可以在实时行情上自动运行（虚拟资金），通过 Web 界面管理策略、查看回测结果、监控模拟账户状态。

---

## 技术决策

| 维度 | 决策 | 原因 |
|------|------|------|
| 前端 | Vue 3 + TypeScript + Vite + ECharts + Pinia | 用户指定，Vue 3 学习曲线平缓 |
| 后端 | FastAPI + SQLAlchemy 2.0 + APScheduler | 异步支持好，WebSocket 内置，生态成熟 |
| 数据库 | SQLite（新增 `data/server.db`） | 沿用阶段一方案，单用户足够 |
| C++ 加速 | 跳过，纯 Python | 列为技术债，后期按需偿还 |
| 部署 | Docker 多容器（Nginx + FastAPI） | 用户要求一步到位 |

## 前端页面

### 1. Dashboard (`/`) — 实时概览
- 4 个 KPI 卡片（总权益、日收益、Sharpe、MaxDD）
- 权益曲线 + 回撤图（ECharts，WebSocket 实时更新）
- 当前持仓表 + 最近成交

### 2. Strategy Manager (`/strategies`) — 策略管理
- 策略列表 + 搜索
- 创建/编辑表单（策略类名 + JSON 参数）
- 关联的回测记录

### 3. Backtest Runner (`/backtest`) — 回测执行
- 配置表单（日期、策略选择、资金、频率）
- 历史运行列表（状态标签）
- 结果查看（权益曲线 + 指标卡 + 成交日志）

### 4. Paper Trading (`/paper`) — 模拟账户
- 账户摘要（实时 WS 推送）
- 模拟 vs 回测对比曲线 + 偏差表
- 最新信号面板 + 成交日志
- 手动触发 / 重置按钮

### 5. Analytics (`/analytics`) — 绩效分析
- 选择已完成回测
- 指标详情（收益率、波动率、Sharpe/Sortino/Calmar、MaxDD、胜率、盈亏比）
- 月度收益热力图
- α/β 归因

## 模拟账户运行机制

```
交易日 15:05 (APScheduler触发)
    │
    ▼
1. 加载 PaperSnapshot (上次状态)
2. 从 PriceStore 获取今日收盘价
3. strategy.generate_signals(today)  ← 复用阶段一策略代码
4. _signals_to_orders → Matcher.match → Portfolio.apply_trade  ← 复用阶段一引擎
5. 写入 paper_snapshot + paper_position
6. WebSocket 广播 portfolio_update 给所有客户端
```

- **状态持久化**：模拟账户数据存 SQLite，服务器重启不丢失
- **T+1 处理**：直接复用阶段一的 `Position.unlock_date`
- **非交易日**：调度器内检查 `is_trading_day()`，假日自动跳过

## Docker 部署

```yaml
# docker-compose.yml
services:
  server:
    build: { context: ., dockerfile: Dockerfile.server }
    ports: ["8000:8000"]
    volumes:
      - ./data:/app/data
      - ./backtest_result:/app/backtest_result

  web:
    build: { context: ., dockerfile: Dockerfile.web }
    ports: ["80:80"]
    depends_on: [server]
```

- `Dockerfile.server`：Python 3.12-slim，安装 quant-engine + FastAPI，uvicorn 启动
- `Dockerfile.web`：多阶段构建，Node 编译 Vite → Nginx 提供静态文件 + 反向代理 `/api` 到 server
- 开发时不用 Docker：`npm run dev` + `uvicorn` 直接跑

## 关键风险与对策

| 风险 | 对策 |
|------|------|
| 动态策略导入失败 | 提供 `strategies/` 目录放用户策略，文档约定模块路径 |
| APScheduler 在假日执行 | job 内部检查 `TradingCalendar.is_trading_day()` |
| Parquet 结果文件积累 | 在 scheduler 加清理 job，保留最近 N 个结果 |
| ECharts 大数据量卡顿 | 对权益曲线降采样到 ~500 点再传给前端 |
| SQLite 并发写入 | 单 worker 进程，SQLite 完全够用 |
