# Phase 4D：证据门禁与跨市场观察准备

## 当前结论

国内基金策略观察已按单市场切片开放；美股策略观察仍保持阻断。基金回测、信号链和成交时点使用独立的 NAV 证据和下一有效净值执行规则，不能复用 A 股回测授权。

## 本轮已实施

- `Run` 增加市场、策略指纹、数据 manifest、数据截止日、日历版本、执行模型和 `eligible_for_observation` 字段。
- 新建回测任务时生成确定性策略指纹（策略类路径、规范化参数和本地策略源代码哈希）。
- 回测完成后只有证据字段完整且为 A 股执行模型时，才标记为可用于观察。
- `StrategyObservation` 关联具体 `backtest_run_id`、市场和策略指纹。
- 创建/启动/每次 tick 前重新校验回测证据；策略参数或源代码变更后，旧回测不能继续授权观察。
- 回测中心展示证据状态、数据截止日、日历和执行模型，避免用户把普通历史记录误认为可观察授权。
- A 股实时观察已采用两阶段 tick：D 日只保存目标权重，下一有效交易日才提交策略订单；目标和幂等键持久化，策略移除的代码以零权重处理。
- 国内基金新增内容地址化 NAV 数据集：Eastmoney 历史响应经过校验后写入本地不可变数据集，SHA-256 内容哈希作为数据集 ID；同一内容重放幂等，净值修订会生成新 ID，不会改写旧数据。
- 新增 `FundNavMomentumStrategy` 与 NAV 回测引擎：支持指定基金池、日/周/月调仓、零费用纸面模型，并将 `next_valid_nav-v1` 和数据集清单写入回测证据。
- 国内基金观察允许使用同市场且 `eligible_for_observation=true` 的基金回测；D 日 NAV 只生成目标，下一有效 NAV 才经官方 Eastmoney 证据校验后创建纸面订单，基金份额按 0.01 精度处理。
- 国内基金下一有效 NAV 的订单执行先写入持久化再平衡计划，再逐项提交纸面订单；每个计划项拥有稳定幂等键。进程在任意订单后中断时，下一次 tick 会复用原计划并恢复未完成项，已成交项不会重复下单；计划保留 `planned/executing/partial/blocked/completed` 状态。
- 再平衡计划在落库前执行完整现金与仓位上限预检，并按卖出优先、买入随后排序；计划主键冲突时复用已提交计划，避免多 worker 重复生成订单提案。
- 观察结束日遇到周末/节假日时，最后一个交易日已生成的待执行目标不会被提前过期；下一有效 NAV 执行完成后才结束观察。幂等键覆盖账户、策略、周期、资金比例、起始日和自动交易开关。
- `/paper` 的账户快照、估值历史、官方基金 NAV 和策略列表均采用请求序列保护，市场/账户快速切换时旧响应不会覆盖当前页面；切换市场后策略选择会重新校准。
- 基金显式 `as_of` 回放与当前日期 tick 共用同一两阶段执行路径；回放不会再通过直提订单绕过现金、仓位和卖出优先预检。
- A 股实时观察已接入同一持久化计划执行器；计划项和纸面订单使用统一幂等键，最终交易日跨周末时也保留待执行目标。

旧版数据库中没有证据字段的 A 股运行记录仅保留兼容读取；它们不能作为基金或美股授权证据。

## 下一门禁：美股准备与持久化部署

1. 美股策略观察仍需先补齐公司行动、调整价、交易日历和费用证据；证据不足时继续 fail-closed，不能自动下单。
2. SQLite 多实例以外的共享存储、备份恢复与部署演练仍需单独验收。

## 本轮门禁已完成

- 再平衡计划已采用数据库条件更新实现 60 秒可过期租约；每个订单项提交前续租，完成、部分完成或阻断后释放租约，进程崩溃可在到期后接管。
- 基金与 A 股均复用同一持久化计划执行器；对应的活动租约拒绝和过期租约接管测试已加入观察回归。
- 跨日恢复会保留同一计划和已完成项，仅刷新未完成项的最新报价与执行日期；被拒绝的计划项可通过显式 retry 接口生成新的幂等尝试并保留原拒单记录。

美股还需拆股/分红、调整价、NYSE 交易时段和纸面成本模型；在这些证据完成前继续返回 409，不开放美股策略观察。

后续研究质量、数据闭环、回测语义和实验可复现施工已登记在 [`docs/phase-4e-research-quality-plan.md`](phase-4e-research-quality-plan.md)，其中未完成项不计入当前交付。

所有阶段继续保持 `paper_only=true`、`live_execution=false`、`can_submit_live=false`。
