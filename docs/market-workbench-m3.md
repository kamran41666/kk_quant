# Phase 3A-M M3 实施记录：行情工作台可用性增强

> 文档状态：历史里程碑。文中的“后续 M4”已完成并有独立验收；当前状态见 [`market-workbench-m4.md`](market-workbench-m4.md)。

## 已交付

- `/api/v1/market/quotes` 对最多 500 个证券代码做服务端校验，并按每批 100 个代码分片请求公共行情源；单批失败会保留结构化 attempts，已有结果仍以 `partial` 明确返回，全部失败才返回 503。500 个上限用于控制常见代理的 URL 长度，工作台当前页只请求 50 个证券。
- 全市场证券列表在当前页显示最新价和涨跌幅；列表仍由服务器分页，行情请求只覆盖当前页，避免一次刷新请求整个 A 股快照。
- K 线图新增成交量独立子图；成交量缺失保持空值，柱状颜色按该周期涨跌显示。MACD、RSI、KDJ 继续使用独立子图，所有子图共享缩放范围。
- 图表 tooltip 增加成交量；指标、成交量和价格空值均留白，不连接不存在的数据点。
- 图表缩放按“证券 + 周期”保存到浏览器本地存储；周期和指标开关偏好也保存，刷新页面后恢复，存储不可用时回退到内存状态。
- 当前页行情失败时保留证券主数据并展示明确的“行情暂不可用”提示，不把缺失价格替换为 0。

## 验证边界

- 分片单测覆盖 205 个代码得到 `100/100/5` 三批，返回 205 条且状态为 `ok`；超过 500 个代码返回 422。
- M2/M3 相关后端定向测试 `20 passed`；全量后端回归 `274 passed, 1 deselected, 4 warnings`（排除既有会等待外部股票池的用例）；前端 Node 单测 `6 passed`，`vue-tsc` 与 Vite 构建通过。
- 独立最终审查：P0=0、P1=0；确认当前页刷新、30 秒刷新、请求失效保护和四类图表子图已生效。
- 公共行情源仍无 SLA；未接入券商、未保存账户密钥、未提供真实下单能力。
