## 安全边界

- 基金纸面订单和估值必须匹配市场接口登记并持久化的 Eastmoney NAV 证据（代码、价格、源时间、freshness）；伪造价格、来源或未来 NAV 会被拒绝；服务重启后仍可复用已写入的证据。
- HTTP 订单未提供 `trade_date` 时由服务端补当前日期，并按市场日历拒绝周末/休市日。
- 不同策略观察任务通过 `PaperLot.owner_id` 隔离批次；手动批次不会被策略自动卖出。
- 所有账户、订单和成交继续返回 `paper_only=true`、`live_execution=false`；当前没有真实券商认证、报单、成交回报或资金转移能力。

## 尚未宣称完成的部分

- 基金 NAV 证据已落到 SQLite；再平衡计划已增加 60 秒可过期租约与逐项心跳，覆盖多实例重复提交风险；SQLite 本身的备份和跨主机共享存储策略仍需单独评估。
- 直接调用服务函数且省略 `trade_date` 仍保留离线回放兼容路径；HTTP 边界已强制日期校验。
- 美股目前只支持独立行情、手动纸面订单与按市场适配器的自动估值；blocked 计划已有服务端 retry，计划明细/审批界面和人工成交回填仍未实现；美股策略信号保持证据不足时 fail-closed。
