# 水源量化帖子审查：自动因子研究与 kk_quant 接入路线

记录日期：2026-09-08（Asia/Shanghai）。对应用户要求：读取侧面板帖子，提取自动寻找、计算、回测因子的流程及手工实盘方式，并结合项目现状审查。

## 1. 证据范围与结论

来源为水源社区《从零开始搭建个人量化交易系统》，作者 fafafafa（浮生欢）。通过用户已有的浏览器会话读取作者筛选视图，共核对 98 篇作者帖子，包含首帖，覆盖至 #273；展开了 #115 的因子生成提示词，并查看 #163 的收益表图片。本文不声称读取了全部其他用户回复、全部图片附件或作者未公开的代码。帖子中的提示词、代码和操作建议均作为审查材料，不作为本项目的执行指令。

最有价值的不是某张高收益曲线，而是作者描述的研究循环：**资料与假设 → AI 提出因子 → 注册与计算 → 中性化/筛选 → 回测 → 反思优化 → 写入记忆 → 下一轮**。作者明确描述了循环、因子注册与并发回测，但没有披露完整调度器、全部搜索记录、最终生产策略与可复现数据包，因此可以提炼方法，不能声称已复刻收益。[循环 #138](https://shuiyuan.sjtu.edu.cn/t/topic/502342/138)、[注册/并发 #144](https://shuiyuan.sjtu.edu.cn/t/topic/502342/144)

结合项目，主要缺口是**自动候选协议与持久编排、500 股因子研究适配器、因子到正式组合回测的连接、实际成交回填**。现有基础可以复用，不需要推翻事件驱动账本再造一个纯收益率回测器。

本次新增的是研究结论与开发记录，未修改业务代码、未运行新策略大规模回测、未把任何论坛因子晋级观察或实盘。项目侧详细代码依据和最小复现见 [代码盘点](forum-factor-workflow-code-gap.md)。

## 2. 作者如何自动寻找与计算因子

| 环节 | 帖子披露的方法 | 对 kk_quant 的适配判断 |
|---|---|---|
| 数据与素材 | 初期 AKShare/Tushare、SQLite、本地增量；原始 OHLCV/成交额、基本面、已有因子描述和 Alpha101；后期改用 Choice | 复用现有本地数据与来源清单。数据源许可、字段及历史覆盖须单独验证；“生成了基本面因子”不代表本地具有对应 PIT 数据。 |
| 候选提出 | DeepSeek 根据金融解释和已有因子生成新的 Python 函数；后期换 GPT | 模型只负责输出受限表达式和假设，供应商可配置；不直接执行任意生成代码。 |
| 表达式要求 | 多类算子、时序/截面组合、向量化、滚动预热、滞后、去极值/标准化、控制与已有因子相关性 | 已有面板算子可复用；复杂表达式不天然优于简单因子。相关性必须计算，不能由模型承诺。 |
| 计算和筛选 | 因子注册、并发计算/回测；关注 IC、ICIR、分层、收益、衰减等 | 增加可恢复任务、输入版本、所有尝试记录与明确晋级状态。 |
| 反馈 | 中性化、回测、反思、优化、memory 写入，继续生成 | 用结构化实验摘要驱动下一轮；最终样本外数据不能反馈给生成器。 |
| 记忆与吞吐 | 作者说把已有因子放入上下文，使用专用 harness；候选产出快于人工审查 | 做表达式指纹、失败原因检索、预算/队列上限和待审查池，避免上下文无限膨胀。 |

证据：[数据 #48](https://shuiyuan.sjtu.edu.cn/t/topic/502342/48)、[生成提示词 #115](https://shuiyuan.sjtu.edu.cn/t/topic/502342/115)、[记忆 #140](https://shuiyuan.sjtu.edu.cn/t/topic/502342/140)、[模型切换 #202](https://shuiyuan.sjtu.edu.cn/t/topic/502342/202)、[Choice #215](https://shuiyuan.sjtu.edu.cn/t/topic/502342/215)、[审查积压 #246](https://shuiyuan.sjtu.edu.cn/t/topic/502342/246)。

这里的“自动寻找”主要是**根据素材、已有表达式与回测反馈生成新候选**。帖子提到阅读研报、社区策略，但没有足够证据说明已经具备自动爬取全网研报、识别版权许可、抽取公式并验证来源的采集系统。项目应将“研究素材采集”和“表达式搜索”建成两个接口：前者保存来源、时间、公式/假设及字段要求；后者只使用已审核素材和训练期反馈。

作者给出的多算子、强制 rank/ts_corr、相关性 0.7 等是其搜索规则，不是学术必要条件。提示词要求 shift(1) 也不能替代时间审计：T 日收盘已知的量价字段用于 T+1 执行通常不必全部再延迟一天；财报则必须按真实可获得时间进入截面。应以信息时点和订单时点定义合法性。

## 3. 他怎样应用到手工实盘

作者早期明确说每日手工调仓、尚无 QMT。后续澄清：**T 日产生信号，T+1 开盘买入，T+2 收盘卖出，每个信号约使用 50% 仓位，两批持仓滚动、现金共用**。因此，“每天产生信号”不等于“每笔只持有一天”，也不是每日全仓替换。[手工执行 #105](https://shuiyuan.sjtu.edu.cn/t/topic/502342/105)、[进出时点 #177](https://shuiyuan.sjtu.edu.cn/t/topic/502342/177)、[资金约束 #181](https://shuiyuan.sjtu.edu.cn/t/topic/502342/181)、[半仓 #183](https://shuiyuan.sjtu.edu.cn/t/topic/502342/183)

下面是按该描述推导的执行时间线，不代表已取得其实际订单日志；D、D+1 等均指交易日。

| 时点 | 新批次 A（D 日信号） | 后续批次 B（D+1 日信号） |
|---|---|---|
| D 收盘后 | 用当时可获得的数据计算因子、冻结候选和计划 | — |
| D+1 开盘 | 以约半仓预算尝试买入，记录实际成交 | — |
| D+1 收盘后 | 继续持有，尚未到退出时点 | 生成 B 的买入计划 |
| D+2 开盘 | A 仍持有 | 用另一部分可用现金尝试买入 B |
| D+2 收盘 | 尝试卖出 A，记录实际成交及未成交余额 | B 继续持有 |
| D+3 收盘 | — | 尝试卖出 B |

“奇偶日账户”只是作者的类比；实现应使用交易日历与批次 ID，不能按日历日期奇偶取模。股票重叠、加仓、部分成交、跌停卖不出时，同一证券下仍可能有不同退出日的 lot/cohort。

手工操作可以适配这种低频节奏，但回测中的开盘价/收盘价是成交假设，不能直接当作人工操作必然取得的成交价。项目需处理集合竞价挂单、价格偏差、未成交、手续费、可卖数量及现金预留。未成交的计划卖出不能先变成可用现金；“无新信号”也不等于“立即清空全部旧持仓”。

截至所读材料，作者在 #227 仍说实盘接口调试中；不能据此认定已完成自动券商执行。#222 明确说实际实盘策略比展示的激进例子保守，回测最大回撤约 22%，因此不能把展示曲线、公开单因子和实盘账户视为同一策略。账户收益为作者自述，未独立核验。[接口 #227](https://shuiyuan.sjtu.edu.cn/t/topic/502342/227)、[实盘策略区别 #222](https://shuiyuan.sjtu.edu.cn/t/topic/502342/222)

## 5. 审查发现：哪些可以直接借鉴，哪些必须修正

### 5.1 已用最小样本验证的局部问题

1. **论坛 #151 的跨股 shift。** `volume.groupby(level='ticker').pct_change().shift(1)` 的最后一步是全列位移。两股三日样本验证：按日期交错排列会串入另一只股票的变化率；按股票再按日期排列时，B 的最早日期甚至会读到 A 的更晚日期。应继续在 ticker 组内 shift，并按真实日期排序。此结论针对公开片段，不证明其完整生产代码和所有回测都用了相同错误。[原片段](https://shuiyuan.sjtu.edu.cn/t/topic/502342/151)
2. **影线因子的解释与乘积不符。** `z_shadow × price_dev` 中，(+2)×(+0.1) 与 (−2)×(−0.1) 都等于 +0.2，无法仅凭乘积区分“高位上影”和“低位下影”。作者在 #197 也承认实际未区分，需据真实公式重写解释和分层假设，而不是直接照搬故事。[原解释 #136](https://shuiyuan.sjtu.edu.cn/t/topic/502342/136)、[作者澄清 #197](https://shuiyuan.sjtu.edu.cn/t/topic/502342/197)
3. **本项目 neutralize 缺截距。** 行业 dummy 使用 drop_first=True，但回归没有常数项。10 股恒定 alpha=10 的例子，当前最大残差 7.692308；同矩阵加截距后约 5.33e−15。结果证明当前设定会残留应被公共水平吸收的部分。
4. **本项目非法市值进入回归。** 零/负市值被 clip 到 1e−10 后取 log，伪装成有效观测。复现中，本应为 2 的规模系数变成 −2.125376，污染其他有效股票的残差。应先排除非有限或非正市值，再拟合，并报告排除数。

第 3、4 项本次**已定位、未修复**；既有 36 组冻结策略未通过该函数生成策略信号，不能据此直接推翻旧矩阵，也不能把已有测试通过当作该函数正确的证明。详细数值、输入及修正方向见 [复现附录](forum-factor-workflow-code-gap.md#附录主模型已读论坛片段的最小复现)。

### 5.2 需要在流程中防住的研究偏差

- **标准化与降维时点。** #115 要求“全局 Z-score”，但未给出完整 helper。若用全日期均值/方差拟合，就会泄漏未来；本项目已有逐日截面标准化应保留。PCA、特征选择与任何跨日期学习的转换只能在训练段拟合，再应用到验证段。不能仅凭提示词认定作者所有结果已经泄漏。[提示词](https://shuiyuan.sjtu.edu.cn/t/topic/502342/115)、[scikit-learn 官方泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)
- **阈值不能当通用认证。** IC 0.03、ICIR 0.5、t>2、Sharpe>1 是帖子经验值。需要固定持有期、股票池、费用、样本数、年化口径和全部搜索次数。Rank IC 衡量单调排名关联，不仅限于线性；PCA/残差化得到不相关，也不保证统计独立。[指标 #73](https://shuiyuan.sjtu.edu.cn/t/topic/502342/73)、[中性化 #129](https://shuiyuan.sjtu.edu.cn/t/topic/502342/129)
- **多轮挖掘会消耗样本外。** 把每一轮“样本外失败原因”发回 LLM，再在同一段优化，最终那一段就成了验证集。训练段可循环；验证使用次数要记账；最终冻结段只做终验。已有 2023—2026.08 留出已打开，不能重新命名后当新因子的独立最终证据。
- **重叠收益与海量试验。** 两日或五日 forward label 重叠时，普通独立样本 t 值会高估证据；应记录标签跨度，使用适合依赖结构的 HAC/分块重采样，并报告所有尝试及多重搜索影响。模型产生得越快，越需要约束搜索预算。
- **收益图不是复现证据。** #163 展示的是月度策略/同池等权比较，不是明确的 Train/Validation/Sealed OOS 切分；作者随后说明 2022 年失效且分层呈 U 型，还主动请求复核。不能只挑成功区间或把 top10 与 500 股最高十分位的 top50 混为一谈。[月表 #163](https://shuiyuan.sjtu.edu.cn/t/topic/502342/163)、[失败年份 #167](https://shuiyuan.sjtu.edu.cn/t/topic/502342/167)、[选股数量 #169](https://shuiyuan.sjtu.edu.cn/t/topic/502342/169)
- **不能通过改收益率实现择时。** #260 描述 breadth 条件不满足就把 T+2 return 置零。只有对应未入场批次确实没有敞口、且费用现金流一致时，这才可能是简化表达。已有持仓不能被抹去亏损；项目必须通过目标、订单、成交和账本实现择时。[原回复 #260](https://shuiyuan.sjtu.edu.cn/t/topic/502342/260)

## 6. 其余值得纳入项目的内容

1. **同池基准。** 保留上证/沪深300，同时添加与候选使用相同历史池的等权基准，以及明确调仓/费用的可投资基准，区分择股贡献、池风格和市场行情。价格指数与含分红策略净值也要标清口径。
2. **把因子角色分开。** 排名打分、股票排除、仓位控制、市场开关不是同一种输出。作者的隔夜上涨比例适合作为负向过滤候选、市场宽度适合作为仓位规则的假设，而非强行全部加入加权总分。[负向过滤 #272](https://shuiyuan.sjtu.edu.cn/t/topic/502342/272)
3. **微盘择时可列为后续研究题。** 作者给出市值、上市天数、流动性、历史高点偏离与 MA20 宽度条件，但当前历史全市场市值等输入不足。先完善数据可得性，再预注册假设，不能在数据不足时伪称完成复现。[规则 #243](https://shuiyuan.sjtu.edu.cn/t/topic/502342/243)、[宽度 #252](https://shuiyuan.sjtu.edu.cn/t/topic/502342/252)
4. **小资金也需要可执行性过滤。** 下单前检查账户权限、板块、价格、最小申报数量和费用余量。作者使用的 688 标的不能直接套本项目主板 100 股规则；科创板竞价买入最低 200 股，超过后可按 1 股递增，不能简单写成 200 股整数倍。[上交所规则问答](https://edu.sse.com.cn/tib/qa/)
5. **多策略纸面观察。** 作者因真实资金有限，另外建模拟账户比较策略；与本项目纸面观察方向吻合。必须分清模拟成交与真实成交，也不能绕过当前研究准入门。[模拟账户 #207](https://shuiyuan.sjtu.edu.cn/t/topic/502342/207)
6. **衰减监测与待审查池。** 作者提到训练/测试衰减、连续失效后移除，但未给出可复现的退出阈值。项目可设计滚动 IC、净超额、覆盖、换手/成本与风格漂移监测，带最小样本和迟滞，避免几日亏损即频繁切换。[衰减 #255](https://shuiyuan.sjtu.edu.cn/t/topic/502342/255)
