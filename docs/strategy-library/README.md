# 策略文档库

本目录统一管理 kk_quant 的策略研究报告。每次分析新策略时，先形成有来源、可验证的研究报告，再决定是否进入实现和回测阶段。研究报告本身不代表策略有效，也不构成收益承诺。

## 状态定义

- `资料核验中`：仍在确认策略来源、作者或原始规则。
- `规则化方案完成，尚未回测`：已经形成无歧义的量化候选规则，但没有绩效结论。
- `回测中`：已冻结一个规则版本，正在执行样本内、样本外和稳健性测试。
- `研究通过`：达到项目预先批准的研究门槛，可以进入模拟盘。
- `模拟观察中`：正在进行有期限、可审计的模拟交易。
- `暂停`：证据不足、数据不足或验证失败，暂不继续。
- `归档`：不再维护，仅保留研究记录。

## 文件规范

- 一个策略一个 Markdown 文件，文件名使用小写英文和连字符，例如 `cycle-of-price-action.md`。
- 新报告从 [_template.md](_template.md) 复制结构，并在本索引登记唯一编号。
- 报告必须明确区分：可核验事实、作者公开规则、量化推导、待检验参数和实际回测结果。
- 网络资料优先采用作者原始材料、赛事或监管机构页面、论文和官方文档；二手材料必须标明证据等级。
- 不得把比赛成绩、单个案例或作者宣传当成可复制的策略绩效。
- 所有规则必须给出信号时点和最早成交时点，禁止含糊描述和未来函数。
- A股报告必须讨论涨跌停、停牌、T+1、申报单位、费用、复权、退市和股票池历史偏差。
- 未执行回测时必须明确写“尚未回测”，不得填写估计收益、夏普、胜率或回撤。
- 规则或参数发生实质变化时提升版本号，并在“修订记录”中说明；不得覆盖或隐去失败结论。

## 标准工作流

1. 核验策略名称、作者、原始出处及宣称业绩。
2. 整理选股、环境、入场、加仓、减仓、退出和风险管理全流程。
3. 将主观语言转为可计算特征、状态和参数区间。
4. 适配A股制度及项目现有能力，列出实现缺口。
5. 冻结研究假设、消融实验、样本外验证和压力测试方案。
6. 更新本索引；只有用户明确要求后，才进入代码实现或回测。
